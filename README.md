# Paradise Nursery - e-plantShopping

Welcome to Paradise Nursery, an online plant shop shopping cart application.

## Description
Paradise Nursery is a dynamic React web application that allows plant enthusiasts to browse a diverse collection of houseplants, view plant details (names, images, descriptions, prices), add plants to a dynamic shopping cart, and seamlessly manage cart items (adjust quantities, view total costs, and remove items).

## Features
- **Landing Page**: Features company name, tagline, and a "Get Started" button to jump into shopping.
- **About Us**: Information about Paradise Nursery's background, vision, and mission.
- **Product Listing**: Displays plants categorized across multiple sections with detailed cards and dynamic "Add to Cart" buttons.
- **Shopping Cart**: Manages selected plants with quantity increments, decrements, deletion, subtotal calculations, and overall cost tracking using Redux state management.

## Tech Stack
- React
- Redux Toolkit (State Management)
- CSS3 & HTML5
